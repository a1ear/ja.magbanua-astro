An author's site that grew from a single landing page into a full blog with its
own admin CMS. Essays, a journal, quotes, and the book, all editable through a
rich-text editor behind a login.

Built on Next.js and TypeScript with Prisma and Supabase Postgres, with row
level security keeping the database closed to anonymous access.
